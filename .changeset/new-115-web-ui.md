支持 115 网盘新版页面

115 新版网盘改为 Next.js SPA，路径从 `/?cid=` 变为 `/storage/allfiles`，旧的路由规则匹配不到，脚本完全不会注入。本次新增新版页面的适配基础与 Aria2 导出功能。

- 新增 `/storage/*` 路由匹配与页面入口，旧版路由保留，未切换新版的用户不受影响
- 新增由 DOM 变化驱动的 Mod 挂载机制：新版切换目录时 URL 行为不可靠，且行 DOM 上不再带 `file_id` / `pick_code`，改为从 React 内部读取文件数据并逐行比对标识
- 文件列表行支持 Aria2 推送按钮，挂载在行内原生操作条上

注意：新版 `file_type` 字段含义与旧版不同（旧版为 `'0'`/`'1'`，新版为扩展名），区分文件与文件夹改用 `fid` 是否存在判断。
